## Context

The client Storybook (8.6) can't be trusted as a picture of the app:

- The preview only provides `BrowserRouter`, while the app root provides React Query, Redux, router, auth and WebSocket contexts. So no feature component can be storied.
- There's no request mocking.
- 11 real story files cover leaf primitives only.
- There are no `play` tests or accessibility checks.
- Storybook and Vitest are two majors behind, and `npm test` needs a browser.

The epic was researched on 2026-09-04/07. On 2026-09-24 it was re-baselined against `develop`, which had changed a lot in between:

- #154 removed Bootstrap, Tailwind and Sass.
- #154 added `Alert`, `FormControls`, `LevelBadge` and `layout/*`.
- `SocketContext` is now exported.

The mocking decision was also reversed (see Decisions).

## Decisions (recorded in #173)

- **Mocking**: MSW with handlers generated by Orval from `api.json`, never hand-written.
- **Workflow**: Storybook runs natively (`npm run storybook`), not in Docker.
- **Titles**: explicit, in a designed hierarchy (`Docs/`, `Styleguide/`, `Shared/`, `UI/`, `System/`, `Features/<Domain>/`, `Loading/`).
- **Chromatic**: removed. No hosted Storybook until #178.
- **pnpm**: #153 runs **after** this epic. Both rewrite `client/package.json` and the lockfile, so never in parallel.

## How to run each phase

- One issue, one branch. #177 is split into the sub-pull-requests its delivery order lists.
- Before coding, read the issue's **Current state** section and re-verify it; each issue was written to be self-contained.
- The verification commands are in each issue. Always include:

  ```bash
  npm run lint
  npm run typecheck
  npm run test:unit
  npm run test:storybook
  npm run build-storybook
  ```

  #333 also runs `npm run build`, then confirms there's no `mockServiceWorker.js` in `dist/`.
- The pull request summary lists the commands and results, and states environment limitations rather than working around them.
- Frontend checks don't need Docker. `npm run orval:file` uses the committed `processor-api/api.json`.
