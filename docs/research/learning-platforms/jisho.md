# Jisho: Audit

> **Category:** Free Japanese–English dictionary built on open datasets
> **Researched:** 2026-10-02 from jisho.org/about

## Snapshot

| Item | Value | Source |
|---|---|---|
| Price | Free | [1] |
| Data | JMdict ("roughly 170 000 entries"), JMnedict, KANJIDIC2, RADKFILE, Jreibun, Tatoeba/Tanaka Corpus, KanjiVG, DBpedia | [1] |
| Licences | EDRDG dictionary files "used in conformance with the Group's licence"; Tatoeba sentences CC-BY; KanjiVG stroke diagrams CC BY-SA 3.0; Wikipedia data CC BY-SA 3.0 / GFDL | [1] |

## Feature assortment

- **Search** by word, kanji, radicals (RADKFILE), handwriting and voice; name search; sentence search [1].
- **Stroke-order diagrams** from KanjiVG [1].
- **Example sentences,** mostly Tatoeba, plus Jreibun sentences written by professional teachers [1].

## Strengths

- **Fast, clean, trustworthy.** It does one job.
- **Open data with clear attribution.** That makes it legally simple and community-maintained.
- **Radical and handwriting search** solves "I can't type this kanji".

## Weaknesses

- **No study layer:** no lists, SRS or progress.
- **No reading context.** It is a lookup tool only.

## Lessons for Japanese VMA

- **Japanese VMA uses the same family of datasets,** so it already has Jisho's reference value plus a study layer on top. That combination is its core positioning.
- **Stroke order via KanjiVG** is a well-understood, attributable addition to the kanji detail page (#352). CC BY-SA 3.0 requires attribution, and adapted diagrams must be shared under the same licence. Keep the SVGs as data, not restyled derivatives, unless the share-alike terms are accepted.
- **Radical-composition search** (pick radicals, see matching kanji) builds on the stored kanji–radical relationships.
- **An attribution page.** Japanese VMA should publish a data-sources page like Jisho's about page. It is required by several licences and builds trust.
