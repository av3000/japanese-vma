<h2>Usage Guidelines</h2>

<h3>Accessibility</h3>
<p>
  When using our color system, ensure that text has sufficient contrast against its background according to WCAG 2.2 AA
  standards:
</p>
<ul>
  <li>Normal text: minimum contrast ratio of 4.5:1</li>
  <li>Large text and non-text UI (borders, icons, focus rings): minimum contrast ratio of 3:1</li>
  <li>Never use colour as the only cue; pair it with visible text or an icon</li>
</ul>

<h3>State Management</h3>
<p>For interactive elements, use the appropriate color variants:</p>
<ul>
  <li>
    Default state: the role (e.g., <code>var(--color-interactive)</code>)
  </li>
  <li>
    Hover state: its hover variant (e.g., <code>var(--color-interactive-hover)</code>)
  </li>
  <li>
    Disabled state: its disabled variant (e.g., <code>var(--color-interactive-disabled)</code>)
  </li>
</ul>

  <h3>CSS Variables</h3>
  <p>
    Component styles use roles, so a theme or a dark scheme can change the colour without touching the component:
  </p>
  <pre>
    {`.my-component {
  background-color: var(--color-interactive);
  color: var(--color-on-interactive);
  border: var(--border-size-sm) solid var(--color-interactive-hover);
}`}
  </pre>
